            Table                   Class : Table (โต๊ะอาหาร)
                                    ทำหน้ าที่เก็บข้อมูลโต๊ะอาหาร จุดที่นั่งรับประทาน พิกัดสแกน QR Code และสถานะการครองโต๊ะ
                                    ของลูกคา
                                    Attribute
- tableId : String
                                    tableId: String -> รหัสประจําตัวโตะอาหารในราน (Primary Key เชน TBL-004)
- seatCapacity : int = 4
                                    seatCapacity: int -> จำนวนที่นั่งรองรับสูงสุดของโตะ (คาเริ่มตน 4 ที่นั่ง)
- tableStatus : String = "ว่าง"
                                    tableStatus: String -> สถานะการใช้งานของโตะ (เชน "วาง", "กําลังใชงาน", "จอง")
- qrCode : String
                                    qrCode: String -> URL หรือ Token ประจําโตะสําหรับใหลูกคาสแกนสั ่งอาหารผาน QR Code

หน้า 19 (344): Composition ⑤ Member ◆ PointTransaction

⏱️ ~20-30 วินาที
👉 จุดที่ต้องชี้บนจอ (Visual Cue):
ชี้ประวัติแต้ม 3 รายการ เหลือ 0 บันทึก แล้วสบตาอาจารย์เพื่อขอบคุณ
💡 ทริคการพูด:
จบอย่างมั่นใจ ยิ้มและขอบคุณผู้ฟัง
💬 คำพูดนำเสนอ (สั้น กระชับ พูดตามนี้ได้เลย):
คู่ที่ 5: Member เป็นเจ้าของ PointTransaction (ประวัติแต้ม)
สมาชิกมีประวัติแต้ม 3 รายการ พอลบบัญชี member.destroy() ประวัติแต้มสะสมทั้งหมดหายไปพร้อมบัญชีทันทีครับ

ทั้ง 5 คู่นี้พิสูจน์ให้เห็นว่าระบบของเราปฏิบัติตามหลัก Clean OOP และ OOAD อย่างถูกต้องสมบูรณ์แบบครับ กลุ่มเราขอจบการนำเสนอเพียงเท่านี้ ขอบคุณครับ

🛡️ คลังคำถามปราบเซียนสำหรับเตรียมตอบอาจารย์ (Q&A Defense)

❓ Q1: ใน Java ไม่มีคำสั่ง delete เหมือนภาษา C++ แล้วเราทำ Composition อย่างไร?
แนวทางการตอบ: "ใน Java หน่วยความจำถูกดูแลโดย Garbage Collector ครับ เราจึงทำ Composition ผ่าน Life-cycle Method คือ destroy() โดยเมื่อ Object ตัวแม่ถูกทำลาย ตัวแม่จะเป็นคนสั่ง clear() และตัดการอ้างอิง Object ลูกทั้งหมด ทำให้ลูกกลายเป็นขยะและถูก Garbage Collector กวาดทิ้งไปพร้อมกันครับ"
❓ Q2: Two-Pass Stock Check ใน FR1 คืออะไร ทำไมต้องทำสองรอบ?
แนวทางการตอบ: "คือการแยกตรวจกับตัดสต็อกออกเป็น 2 รอบครับ รอบแรกวนตรวจวัตถุดิบทุกอย่างให้มั่นใจว่าพอครบ 100% ก่อน เมื่อผ่านครบแล้วรอบสองจึงค่อยตัดสต็อกจริง ป้องกันปัญหาหักชิ้นแรกไปแล้วของชิ้นถัดไปหมดครับ"
❓ Q3: ทำไม OrderItem ต้องเก็บราคาและสูตรของตัวเอง ทั้งที่มี Menu อยู่แล้ว?
แนวทางการตอบ: "เพื่อป้องกัน Historical Data Drift ครับ ถ้าร้านปรับราคาเมนูในวันพรุ่งนี้ บิลย้อนหลังที่ลูกค้าเคยสั่งไปเมื่อวานจะต้องไม่เปลี่ยนราคาตาม จึงต้อง Snapshot ค่าเก็บไว้ใน OrderItem ครับ"
❓ Q4: ทำไมความสัมพันธ์ของ Order กับ Table ถึงเป็นแค่ Association ไม่ใช่ Composition?
แนวทางการตอบ: "เพราะเรื่อง Lifecycle ครับ โต๊ะอาหารมีอยู่จริงในร้านมาก่อนออเดอร์ และเมื่อออเดอร์ถูกยกเลิกหรือจ่ายเงินเสร็จ โต๊ะก็ยังคงอยู่ที่ร้านรับลูกค้ารายใหม่ได้ ไม่ได้พังหรือหายไปตามออเดอร์ครับ"
❓ Q5: ทำไมโปรเจกต์นี้ถึงไม่มีการใช้ Framework เช่น Spring Boot?
แนวทางการตอบ: "เพราะวิชา OOAD ต้องการพิสูจน์ความเข้าใจในกลไกพื้นฐานของ OOP ครับ การใช้ Core Java ทำให้เห็นการทำงานของ Constructor, Encapsulation, Reference และ Garbage Collection ครบถ้วนทุกบรรทัดอย่างโปร่งใสครับ"

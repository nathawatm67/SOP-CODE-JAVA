Composition คือ ความสัมพันธ์ระหว่างคลาสแบบ "has a" (ประกอบด้วย) ที่มีคุณสมบัติ "ความเป็นเจ้าของ (ownership)" คลาสเจ้าของเรียกว่า owning object ส่วนคลาสที่ถูกประกอบเรียกว่า contained object โดย "เมื่อไม่มี owning object จะไม่มี contained object" เช่น a Document has many Pages ถ้าไม่มี Document ก็ไม่มี Page

สัญลักษณ์ข้าวหลามตัดทึบ (◆) เส้นที่หัวข้างหนึ่งเป็นสี่เหลี่ยมข้าวหลามตัดทึบ อยู่ฝั่งคลาสเจ้าของ หมายถึงคลาสนั้นประกอบขึ้นด้วยคลาสที่อยู่ปลายอีกข้าง

วิธีหา Composition รวบรวม Use Case / User Story → หาประโยค "has a" → ทดสอบว่าถ้าไม่มีเจ้าของ ส่วนประกอบยังอยู่ไหม → ทำซ้ำจนครบ → รวมทุก Association ไว้ในไดอะแกรมเดียว

เขียนเป็น code อย่างไร (หลักปฏิบัติ 4 ข้อ)

1. เก็บส่วนประกอบเป็น field private ในคลาสเจ้าของ
2. เจ้าของสร้างส่วนประกอบเองด้วย new
3. คลาสอื่นไม่ถือส่วนประกอบไว้โดยตรง
4. เมื่อเจ้าของถูกลบ/ยกเลิก ส่วนประกอบหายไปด้วย

class Document & class Page
class Document { private List<Page> pages = new ArrayList<>(); // has many Pages public void addPage(String text) { pages.add(new Page(text)); // Document สร้าง Page เอง } } class Page { private String text; Page(String text) { this.text = text; } // ไม่ใส่ public }
Page ถูกสร้างและเก็บไว้ใน Document ที่เดียว — ไม่มี Document ก็ไม่มี Page
